API

Planning and running

CacheAwareConv.ConvPlan — Type
ConvPlan(T, xsize, wsize; stride = 1, pad = 0, dilation = 1, groups = 1,
         flipped = false, nthreads = Threads.nthreads(), cache = cache_info())

Pre-plan a convolution of arrays with element type T: input of size xsize (spatial..., C_in, batch) and weights of size wsize (kernel..., C_in ÷ groups, C_out). The plan owns every scratch buffer, so conv! with a plan does not allocate.

Keyword arguments follow the deep-learning convention: stride, pad (an integer, one value per spatial dimension, or (lo, hi) pairs per dimension), dilation, channel groups, and flipped (false performs a true convolution with the kernel reversed, true a cross-correlation). nthreads is the maximum number of tasks used; cache overrides the cache sizes the blocking is derived from. The buffers needed by ∇conv_data! and ∇conv_filter! are allocated on first use unless gradients = true, which allocates them up front. flat forces the flattened-row traversal for narrow outputs on or off (default: automatic).

See also plan_conv, output_size.

CacheAwareConv.conv! — Function
conv!(y, x, w, plan::ConvPlan; bias = nothing, σ = identity, accumulate = false)

Compute y = σ.(conv(x, w) .+ bias) in place using the pre-planned blocking. bias, if given, is a vector with one entry per output channel. With accumulate = true the result is added to the existing contents of y instead (y .+= conv(x, w) .+ bias; σ must then be identity). All three arrays must have the plan's element type and sizes. Returns y.

The activation σ is fused into the tile epilogue while the output tile is still in cache. This fused path has no automatic-differentiation rules: for training, use σ = identity (or conv_bias) and apply the activation as a separate broadcast, which is what the Lux and Flux layers do.

Geometry

CacheAwareConv.ConvGeometry — Type
ConvGeometry{N, S, P}

Immutable description of a convolution: the sizes of the input x (I_1, …, I_S, C_in, B), the weights w (K_1, …, K_S, C_in ÷ groups, C_out), and the resulting output y (O_1, …, O_S, C_out, B), together with the spatial stride, zero pad (stored as (lo_1, hi_1, …, lo_S, hi_S)), dilation, channel groups, and whether the kernel is flipped (false = true convolution, true = cross-correlation).

N = S + 2 is the number of array dimensions. Padding entries may be negative, which crops the input.

Index convention (1-based) for the spatial dimension i:

x_index = (o - 1) * stride_i - lo_i + 1 + (k′ - 1) * dilation_i

with k′ = k when flipped and k′ = K_i - k + 1 otherwise.

source
CacheAwareConv.SamePad — Type
SamePad()

Padding marker for the layer constructors: pad so that the output has the same spatial size as the input when stride == 1 (extra padding goes to the low side when the total is odd, as in Lux and Flux).

Hardware parameters

CacheAwareConv.CacheInfo — Type
CacheInfo(; l1, l2, l3, linesize)

Per-core cache sizes in bytes used to derive the blocking of a ConvPlan. The default, cache_info, queries CPUSummary.jl; pass an explicit CacheInfo to a plan to override it (useful for testing the blocking logic or tuning by hand).

source
CacheAwareConv.cache_info — Function
cache_info()

Per-core L1/L2/L3 sizes as reported by CPUSummary.jl, with conservative fallbacks for levels the platform does not report (a missing level is taken to be eight times the previous one).

source
CacheAwareConv.compute_type — Function
compute_type(T)

Element type used inside the packed buffers and the microkernel for arrays of element type T. Float16 is computed in Float32; complex types are split into real planes of compute_type(real(T)); everything else is unchanged.

source
CacheAwareConv.vector_width — Function
vector_width(Tc)

SIMD lanes per vector for compute type Tc on this machine (1 for the scalar path).

source
CacheAwareConv.register_tile — Function
register_tile(Tc, nplanes) -> (MR, NR)

Register-tile shape of the microkernel: MR vectors along the output width times NR output channels, chosen from the architecture's vector register count so that nplanes * MR * NR accumulators plus nplanes * MR input vectors and one broadcast fit without spilling. With a single output channel per group (cout == 1, the stencil case) the tile is MR × 1 with a larger MR.

source
CacheAwareConv.nplanes — Function
nplanes(T)

Number of real planes an element of type T is packed into: 1 for real types, 3 for complex types (re, im, re + im for the 3-multiplication kernel).
